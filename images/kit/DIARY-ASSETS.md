# Mesa diary scene

Created using the built-in image_gen tool from the existing Mesa notebook and pen references. These are enhanced product visualizations, not new photographs. Original assets are preserved.

## Assets

- `notebook-open.png`: 1536 × 1024 transparent open spread.
- `notebook-hq.png`: 1103 × 1426 transparent cover.
- `pen-hq.png`: 725 × 2170 transparent pen.

The handwritten note is a code-native SVG path: “Think big. Start here.” The same path drives the pen nib. The chapter gets 2.4 viewport heights, and later chapter positions are measured from the layout. Reduced motion displays the complete written spread.
